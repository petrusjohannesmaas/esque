# One tool to back up every app's database

25 November 2026 | Issue #1

## What changed

Esque replaces the old backup script with one tool you install once. It shows a menu of your apps, and each one keeps its own folder, database file, passphrase and S3 location. From an app's page you can back up now, list its backups, restore one, change its S3 details, reveal its passphrase, rename it or remove it.

A backup is encrypted with that app's passphrase and uploaded to its S3 location with a name based on the app and the time. You can accept the suggested name or type your own. Restoring downloads a backup, checks that it opens, and saves the database as a new file, so the live one is never touched.

## Why it matters

Adding another app no longer means copying and editing a script, and no passphrase has to sit in a script. Each app's settings stay separate, so a change to one app's S3 details never affects another. Backups written by the old script still restore, and any backup can also be restored on a machine with plain openssl.
